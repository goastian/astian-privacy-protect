# Changelog

All significant changes to this project will be documented in this file.

## [2.0.5] - 2024-01-15

### Added
- Ad blocker based on Ghostery AdBlocker
- Compatibility with Mozilla Firefox and Chromium browsers
- Detailed statistics system with real-time metrics
- Modern user interface with popup and options page
- Advanced performance optimization system
- Custom list management (whitelist/blacklist)
- Statistics export in JSON format
- High-performance mode for better performance
- Memory and CPU usage monitoring
- Smart cache with configurable TTL
- Batch processing of requests
- Automatic cleanup of unused resources
- Unit tests with Jest
- ESLint configuration for code quality
- Build scripts for Firefox and Chromium
- Complete documentation in README.md

### Technical Features
- TypeScript for static typing
- Webpack for optimized bundling
- Compatibility with Manifest V2 (Firefox) and V3 (Chromium)
- Statistics system with local persistence
- Performance optimizations specific to extensions
- Modular and extensible architecture
- Robust error handling
- Detailed logging for debugging

### Performance Metrics
- Typical memory consumption: < 50MB
- Initialization time: < 500ms
- Filter compatibility: 99% with Easylist/uBlock Origin
- Automatic filter updates every 24 hours
- Real-time request processing

### User Interface
- Popup with real-time statistics
- Options page with advanced settings
- Visual status indicators
- Statistics graphs by block type
- Status and error notifications
- Responsive and modern design

### Settings
- Blocker status (enable/disable)
- Configurable block types (ads, trackers, social)
- Customizable filter refresh interval
- Configurable memory limits
- Custom domain lists
- Optional high-performance mode

### Development
- Automated build scripts
- Unit tests with coverage
- Linting with ESLint
- Hot reload for development
- Automatic packaging for distribution
- Complete API documentation
